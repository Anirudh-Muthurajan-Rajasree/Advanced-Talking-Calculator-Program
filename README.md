# Advanced-Talking-Calculator-Program
Here is a calculator program that I have created on Windows form app (it works very well in resolutions with 1360 *768) along with explanation the some of the main features are as follows

This program can be viewed in 11 languages:
1) English
2) Russian (Русский)
3) Chinese (中文)
4) Italian (Italiano)
5) German (Deutsch)
6) French (Français)
7) Spanish (Español)
8) Tamil (தமிழ்)
9) Kannada (ಕನ್ನಡ)
10) Hindi (हिन्दी)
11) Japanese (日本語)

It can also speak during calculations with 3 different tones that can be changed manually. 

The results can be copied to clipboard. 

It also has other cool functions (Like the speed of the speech can be adjusted, save in notepad format, etc)
